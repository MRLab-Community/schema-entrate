### ASSISTANT
Hai fatto un'ottima osservazione. La presenza di **`$A$48`** (la riga *sopra* quella dove inizia la lista) è fondamentale per il corretto funzionamento di questa formula matriciale in Excel 2019.

Ecco la spiegazione logica:

### 1. Il meccanismo "Espansione Progressiva"
La formula `CONTA.SE($A$48:A48; ...)` serve a dire a Excel: *"Controlla quali clienti ho già inserito nelle celle SOPRA questa, in modo da non ripetere quelli già presenti."*

*   Quando scrivi la formula nella cella **A49**, l'intervallo `$A$48:A48` si riferisce solo alla cella **A48**.
*   Quando trascini la formula verso il basso in **A50**, l'intervallo diventa automaticamente `$A$48:A49` (grazie al riferimento misto: `$A$48` è bloccato, `A48` no).
*   In **A51**, l'intervallo sarà `$A$48:A50`, e così via.

### 2. Perché proprio A48?
Dobbiamo iniziare il conteggio dei "già inseriti" dalla riga immediatamente precedente al primo dato.
*   Se usassimo `$A$49:A49` nella prima cella, l'intervallo includerebbe la cella stessa che stiamo calcolando, creando potenziali conflitti o riferimenti circolari logici.
*   Usando `$A$48:A48` nella cella A49, diciamo ad Excel: *"Guarda le celle da A48 fino alla riga sopra di me. Se il cliente è già lì, saltalo. Se non è lì, prendilo."*

### 3. Cosa c'è in A48?
Di solito, in **A48** si mette l'intestazione della colonna, ad esempio **"CLIENTI UNICI"** o semplicemente si lascia vuota.
*   Se in A48 c'è del testo (es. "CLIENTI"), la funzione `CONTA.SE` conterà quante volte quel testo appare nell'elenco delle entrate. Siccome "CLIENTI" non è un nome di cliente reale, il conteggio sarà 0, e la formula funzionerà perfettamente ignorando l'intestazione.

### Riassunto Visivo

| Cella | Formula (semplificata) | Intervallo Controllato (`CONTA.SE`) | Risultato |
| :--- | :--- | :--- | :--- |
| **A48** | *Intestazione: "CLIENTI"* | - | Testo statico |
| **A49** | `...CONTA.SE($A$48:A48;...)` | Guarda solo **A48** | Trova il 1° cliente unico |
| **A50** | `...CONTA.SE($A$48:A49;...)` | Guarda **A48 e A49** | Trova il 2° cliente unico (ignora quello in A49) |
| **A51** | `...CONTA.SE($A$48:A50;...)` | Guarda **A48, A49, A50** | Trova il 3° cliente unico (ignora quelli sopra) |

### Conclusione
L'uso di **`$A$48`** è una tecnica standard in Excel per creare elenchi dinamici senza duplicati. Assicurati solo che:
1.  La cella **A48** contenga un'intestazione (es. "CLIENTI") o sia vuota.
2.  Tu prema **CTRL + SHIFT + INVIO** quando inserisci la formula per la prima volta in A49.
3.  Trascini la formula verso il basso partendo da A49.

Se vuoi essere ancora più sicuro, puoi cambiare l'intestazione in A48 in qualcosa che sicuramente non apparirà come nome cliente, tipo "---".

### Codice VBA

```vba
Sub AggiornaTopZoneCarico()
    Dim wsZona As Worksheet
    Dim wsStats As Worksheet
    Dim lastRow As Long
    Dim i As Long, j As Long, k As Long
    Dim zonaNome As String
    Dim zonaCount As Integer
    Dim tempName As String
    Dim tempCount As Integer
    
    ' Imposta i fogli di lavoro
    Set wsZona = ThisWorkbook.Sheets("Zona di Carico")
    Set wsStats = ThisWorkbook.Sheets("STATS S.")
    
    ' Pulisce l'area di destinazione in STATS S. (W49:Y73)
    wsStats.Range("W49:Y73").ClearContents
    
    ' Definiamo gli array per memorizzare i dati temporaneamente
    ' Max 26 zone (da riga 4 a 29)
    Dim zones(1 To 26) As String
    Dim counts(1 To 26) As Integer
    Dim validCount As Integer
    
    validCount = 0
    
    ' 1. Lettura dei dati dal foglio Zona di Carico
    ' Range D4:D29 per nomi, G4:G29 per conteggi
    For i = 4 To 29
        zonaNome = wsZona.Cells(i, 4).Value ' Colonna D
        zonaCount = wsZona.Cells(i, 7).Value ' Colonna G
        
        ' Verifica se è un numero valido e maggiore di 0
        If IsNumeric(zonaCount) And zonaCount > 0 Then
            validCount = validCount + 1
            zones(validCount) = zonaNome
            counts(validCount) = zonaCount
        End If
    Next i
    
    ' Se non ci sono zone attive, esce
    If validCount = 0 Then Exit Sub
    
    ' 2. Ordinamento (Bubble Sort semplice ed efficace per pochi dati)
    ' Ordina in ordine decrescente per conteggio camion
    For i = 1 To validCount - 1
        For j = i + 1 To validCount
            If counts(j) > counts(i) Then
                ' Scambia conteggi
                tempCount = counts(i)
                counts(i) = counts(j)
                counts(j) = tempCount
                
                ' Scambia nomi
                tempName = zones(i)
                zones(i) = zones(j)
                zones(j) = tempName
            End If
        Next j
    Next i
    
    ' 3. Scrittura dei risultati nel foglio STATS S. a partire da W49
    ' W = Nome Zona, X = Nr Camion, Y = Tempo Medio (opzionale, calcolato dopo)
    
    For k = 1 To validCount
        ' Scrive il nome della zona in colonna W
        wsStats.Cells(48 + k, 23).Value = zones(k) ' 23 è la colonna W
        
        ' Scrive il numero di camion in colonna X
        wsStats.Cells(48 + k, 24).Value = counts(k) ' 24 è la colonna X
        
        ' Opzionale: Calcola subito il tempo medio per questa zona
        ' Usa la formula MEDIA.SE direttamente nella cella Y per mantenerla dinamica
        ' Oppure possiamo scriverla come valore statico se preferisci
        Dim formulaMedia As String
        formulaMedia = "=SE.ERRORE(MEDIA.SE(ENTRATE!$P$2:$P$202; W" & (48 + k) & "; ENTRATE!$AZ$2:$AZ$202); """")"
        wsStats.Cells(48 + k, 25).Formula = formulaMedia ' 25 è la colonna Y
    Next k
    
End Sub
```

### Come funziona questa soluzione:
1.  **Nessun errore `#DIV/0!` o `#N/D`**: La macro controlla esplicitamente `If zonaCount > 0`.
2.  **Gestione Duplicati**: Se "STR.9" e "9/PICKING" hanno entrambi 15 camion, li inserirà entrambi nell'elenco, uno dopo l'altro. L'ordine tra due valori uguali dipenderà dall'ordine originale nel foglio "Zona di Carico", ma entrambi saranno presenti.
3.  **Velocità**: Essendo solo 26 righe, l'esecuzione è istantanea.
4.  **Colonna Y (Tempo Medio)**: La macro inserisce automaticamente la formula `MEDIA.SE` nella colonna Y accanto a ogni zona elencata, così avrai anche il tempo medio aggiornato senza fare nulla.

```vba
Function CalcolaDurataConPausa(oraEntrata As Variant, oraUscita As Variant) As Double
    ' Calcola la durata in giorni Excel escludendo la pausa pranzo 11:30-13:00 (1.5 ore = 0.0625 giorni)
    
    Dim inizioPausa As Double
    Dim finePausa As Double
    Dim durata As Double
    Dim sovrapposizione As Double
    
    If IsEmpty(oraEntrata) Or IsEmpty(oraUscita) Then
        CalcolaDurataConPausa = 0
        Exit Function
    End If
    
    inizioPausa = TimeValue("11:30")
    finePausa = TimeValue("13:00")
    
    ' Durata totale
    durata = oraUscita - oraEntrata
    
    ' Calcola sovrapposizione con la pausa
    sovrapposizione = 0
    
    ' Caso 1: Entrata e uscita nello stesso giorno
    If Int(oraEntrata) = Int(oraUscita) Then
        If oraEntrata < finePausa And oraUscita > inizioPausa Then
            sovrapposizione = Application.WorksheetFunction.Min(oraUscita, finePausa) - _
                              Application.WorksheetFunction.Max(oraEntrata, inizioPausa)
        End If
    Else
        ' Caso 2: Attraversa mezzanotte o più giorni
        ' Per semplicità, sottraiamo la pausa solo se il carico inizia prima delle 13:00
        ' e finisce dopo le 11:30 del giorno successivo
        If TimeValue(oraEntrata) < finePausa Then
            sovrapposizione = finePausa - Application.WorksheetFunction.Max(TimeValue(oraEntrata), inizioPausa)
        End If
        If TimeValue(oraUscita) > inizioPausa Then
            sovrapposizione = sovrapposizione + Application.WorksheetFunction.Min(TimeValue(oraUscita), finePausa) - inizioPausa
        End If
    End If
    
    ' Assicurati che la sovrapposizione non sia negativa
    If sovrapposizione < 0 Then sovrapposizione = 0
    
    CalcolaDurataConPausa = durata - sovrapposizione
End Function
```

### 1. Ragionamento sull'Esempio (12:02 - 14:09)

Se un camion entra alle **12:02** ed esce alle **14:09**:

*   **Sovrapposizione Pausa:** La pausa è dalle 12:00 alle 13:30. Il camion è presente in magazzino durante tutta la pausa (o quasi).

*   **Tempo di Carico Effettivo (Colonna AZ):**

```vba
Function CalcolaDurataNetta(oraEntrata As Variant, oraUscita As Variant) As Double
    ' Calcola la durata escludendo la pausa pranzo 12:00 - 13:30
    ' Restituisce il valore in giorni Excel
    
    Dim inizioPausa As Double
    Dim finePausa As Double
    Dim durataTotale As Double
    Dim sovrapposizione As Double
    Dim inizioOverlap As Double
    Dim fineOverlap As Double
    
    ' Se mancano dati, restituisci 0
    If IsEmpty(oraEntrata) Or IsEmpty(oraUscita) Then
        CalcolaDurataNetta = 0
        Exit Function
    End If
    
    ' Definizione orari pausa (12:00 e 13:30)
    inizioPausa = TimeValue("12:00")
    finePausa = TimeValue("13:30")
    
    ' Durata totale lorda
    durataTotale = oraUscita - oraEntrata
    
    ' Calcolo sovrapposizione con la pausa
    sovrapposizione = 0
    
    ' Assumiamo che entrata e uscita siano nello stesso giorno lavorativo per semplicità statistica giornaliera
    ' Se l'uscita è prima dell'inizio pausa o entrata dopo fine pausa, sovrapposizione è 0
    If oraUscita <= inizioPausa Or oraEntrata >= finePausa Then
        sovrapposizione = 0
    Else
        ' Calcola l'intersezione temporale
        inizioOverlap = Application.WorksheetFunction.Max(TimeValue(oraEntrata), inizioPausa)
        fineOverlap = Application.WorksheetFunction.Min(TimeValue(oraUscita), finePausa)
        
        If fineOverlap > inizioOverlap Then
            sovrapposizione = fineOverlap - inizioOverlap
        End If
    End If
    
    ' Risultato netto
    CalcolaDurataNetta = durataTotale - sovrapposizione
    
    ' Evita risultati negativi per errori di inserimento orari
    If CalcolaDurataNetta < 0 Then CalcolaDurataNetta = 0
    
End Function
```

### ASSISTANT
Hai ragione, il problema è nel codice VBA. La funzione `TimeValue` estrae solo l'orario, ma se le celle `I2` e `K2` contengono **Data + Ora** (es. `30/04/2026 12:02`), la sottrazione diretta `oraUscita - oraEntrata` funziona correttamente per la durata totale, ma il calcolo della sovrapposizione con `TimeValue` potrebbe non allinearsi perfettamente se ci sono differenze di data o se Excel interpreta i valori in modo diverso.

Inoltre, c'è un errore logico sottile: se `oraEntrata` e `oraUscita` sono valori completi (Data+Ora), usare `TimeValue` su di essi restituisce solo la parte oraria come frazione di giorno (es. 0,5 per le 12:00). Ma la variabile `durataTotale = oraUscita - oraEntrata` è corretta. Il problema è che stiamo confrontando `TimeValue(oraEntrata)` con `inizioPausa` (che è pure una frazione di giorno), il che dovrebbe funzionare.

Tuttavia, per essere sicuri al 100% e gestire anche casi limite (es. mezzi entrati prima delle 12:00 e usciti dopo le 13:30), riscriviamo la funzione in modo più robusto usando direttamente i valori numerici di Excel senza convertire in `TimeValue` dove non necessario.

### Codice VBA Corretto e Robusto

Sostituisci la funzione esistente nel **Modulo 15** con questa versione aggiornata:

```vba
Function CalcolaDurataNetta(oraEntrata As Variant, oraUscita As Variant) As Double
    ' Calcola la durata netta escludendo la pausa pranzo 12:00 - 13:30
    ' I parametri devono essere valori orari Excel (es. 0,5 per 12:00)
    
    Dim inizioPausa As Double
    Dim finePausa As Double
    Dim durataTotale As Double
    Dim sovrapposizione As Double
    
    ' Se mancano dati, restituisci 0
    If IsEmpty(oraEntrata) Or IsEmpty(oraUscita) Then
        CalcolaDurataNetta = 0
        Exit Function
    End If
    
    ' Verifica che siano numeri validi
    If Not IsNumeric(oraEntrata) Or Not IsNumeric(oraUscita) Then
        CalcolaDurataNetta = 0
        Exit Function
    End If
    
    ' Definizione orari pausa (12:00 = 0,5; 13:30 = 0,5625)
    ' Usiamo TimeValue per ottenere la frazione di giorno corretta
    inizioPausa = TimeValue("12:00")
    finePausa = TimeValue("13:30")
    
    ' Durata totale lorda
    durataTotale = oraUscita - oraEntrata
    
    ' Se la durata è negativa (errore inserimento), restituisci 0
    If durataTotale < 0 Then
        CalcolaDurataNetta = 0
        Exit Function
    End If
    
    ' Calcolo sovrapposizione con la pausa
    ' Estraiamo solo la parte oraria (frazione di giorno) da entrata e uscita
    Dim oraEntrataFrac As Double
    Dim oraUscitaFrac As Double
    
    oraEntrataFrac = oraEntrata - Int(oraEntrata) ' Rimuove la data, tiene solo l'ora
    oraUscitaFrac = oraUscita - Int(oraUscita)     ' Rimuove la data, tiene solo l'ora
    
    sovrapposizione = 0
    
    ' Controlla se c'è sovrapposizione con la fascia 12:00-13:30
    ' Caso 1: Entrata prima della fine pausa E Uscita dopo l'inizio pausa
    If oraEntrataFrac < finePausa And oraUscitaFrac > inizioPausa Then
        ' Calcola l'intersezione
        Dim inizioOverlap As Double
        Dim fineOverlap As Double
        
        inizioOverlap = Application.WorksheetFunction.Max(oraEntrataFrac, inizioPausa)
        fineOverlap = Application.WorksheetFunction.Min(oraUscitaFrac, finePausa)
        
        If fineOverlap > inizioOverlap Then
            sovrapposizione = fineOverlap - inizioOverlap
        End If
    End If
    
    ' Risultato netto
    CalcolaDurataNetta = durataTotale - sovrapposizione
    
    ' Evita risultati negativi
    If CalcolaDurataNetta < 0 Then CalcolaDurataNetta = 0
    
End Function
```

### Cosa è cambiato:
1.  **Estrazione Frazione Oraria**: Invece di usare `TimeValue(oraEntrata)` (che può dare problemi se la cella contiene testo o formati strani), usiamo `oraEntrata - Int(oraEntrata)`. Questo è matematicamente più sicuro in Excel per isolare la parte oraria da un valore Data+Ora.
2.  **Controlli di Validità**: Aggiunti controlli `IsNumeric` per evitare errori se le celle sono vuote o contengono testo.
3.  **Logica Sovrapposizione**: La condizione `If oraEntrataFrac < finePausa And oraUscitaFrac > inizioPausa` assicura che calcoliamo la sovrapposizione solo se il carico "attraversa" effettivamente la finestra della pausa.

### 2. Macro VBA per l'Archiviazione Automatica

Questa macro deve essere inserita nel file **Generatore Schema Entrate**. Il momento migliore per eseguirla è **prima** che il generatore chiuda il file giornaliero appena creato, oppure come passo finale della generazione.

**Logica:**
1.  Apre temporaneamente il file `Schema Entrate [Data].xlsm` appena generato.
2.  Legge le righe compilate (dalla 2 alla 202).
3.  Copia i dati rilevanti nel foglio `DB_STORICO`.
4.  Calcola la durata in minuti usando la logica della pausa pranzo (12:00-13:30).
5.  Salva e chiude il file storico.

#### Codice VBA (Da inserire nel Modulo del Generatore)

```vba
Sub ArchiviaDatiGiornalieri(PercorsoFileGiornaliero As String, DataRiferimento As Date)
    Dim wbGiornaliero As Workbook
    Dim wsEntrate As Worksheet
    Dim wsStorico As Worksheet
    Dim lastRowStorico As Long
    Dim i As Long, j As Long
    Dim zonaNome As String
    Dim spuntatore As String
    Dim oraEntrata As Variant
    Dim oraUscita As Variant
    Dim durataMinuti As Double
    
    ' Disattiva aggiornamenti schermo per velocità
    Application.ScreenUpdating = False
    Application.Calculation = xlCalculationManual
    
    On Error GoTo GestoreErrore
    
    ' Apri il file giornaliero in sola lettura/background
    Set wbGiornaliero = Workbooks.Open(Filename:=PercorsoFileGiornaliero, ReadOnly:=True, UpdateLinks:=False)
    Set wsEntrate = wbGiornaliero.Sheets("ENTRATE")
    
    ' Riferimento al foglio DB_STORICO (presumibilmente nel file Generatore o in un file Archivio aperto)
    ' Assumiamo che DB_STORICO sia nel file dove risiede questa macro (Generatore)
    Set wsStorico = ThisWorkbook.Sheets("DB_STORICO")
    
    ' Trova l'ultima riga libera nello storico
    lastRowStorico = wsStorico.Cells(wsStorico.Rows.Count, "A").End(xlUp).Row + 1
    
    ' Ciclo attraverso le righe dello schema entrate (2 to 202)
    For i = 2 To 202
        ' Controlla se c'è una targa (indicatore di riga valida)
        If Trim(wsEntrate.Cells(i, 1).Value) <> "" Then
            
            ' Recupera dati base
            oraEntrata = wsEntrate.Cells(i, 9).Value  ' Colonna I
            oraUscita = wsEntrate.Cells(i, 11).Value   ' Colonna K
            spuntatore = Trim(wsEntrate.Cells(i, 12).Value) ' Colonna L
            zonaNome = Trim(wsEntrate.Cells(i, 16).Value)   ' Colonna P
            
            ' Gestione Multizona: Se P è "MULTIZONA", leggi da R
            If UCase(zonaNome) = "MULTIZONA" Then
                zonaNome = Trim(wsEntrate.Cells(i, 18).Value) ' Colonna R
                ' Se ci sono più zone separate da |, potresti volerle salvare tutte in una cella
                ' o creare righe multiple. Per semplicità storica, salviamo la stringa completa.
            End If
            
            ' Calcolo Durata in Minuti (usando la logica già testata)
            durataMinuti = 0
            If Not IsEmpty(oraEntrata) And Not IsEmpty(oraUscita) Then
                ' Chiama la funzione CalcolaDurataNetta se è disponibile nel Generatore, 
                ' altrimenti usa una logica semplificata qui per evitare dipendenze
                ' Nota: È meglio avere la funzione CalcolaDurataNetta anche nel Generatore
                durataMinuti = CalcolaDurataNetta(oraEntrata, oraUscita) * 1440 ' Converti giorni in minuti
            ElseIf Not IsEmpty(oraEntrata) And IsEmpty(oraUscita) Then
                ' Se ancora dentro, calcola fino ad ADESSO() o lascia vuoto? 
                ' Per lo storico, di solito si archiviano solo i completati, oppure si segna come PENDENTE
                durataMinuti = -1 ' Codice per pendente
            End If
            
            ' Scrivi i dati nel DB_STORICO
            With wsStorico
                .Cells(lastRowStorico, 1).Value = DataRiferimento       ' Data Giornaliera
                .Cells(lastRowStorico, 2).Value = wsEntrate.Cells(i, 1).Value ' Targa
                .Cells(lastRowStorico, 3).Value = wsEntrate.Cells(i, 2).Value ' Vettore
                .Cells(lastRowStorico, 4).Value = wsEntrate.Cells(i, 3).Value ' Cliente
                .Cells(lastRowStorico, 5).Value = wsEntrate.Cells(i, 4).Value ' Merce
                .Cells(lastRowStorico, 6).Value = oraEntrata            ' Ora Entrata
                .Cells(lastRowStorico, 7).Value = oraUscita             ' Ora Uscita
                .Cells(lastRowStorico, 8).Value = spuntatore            ' Spuntatore
                .Cells(lastRowStorico, 9).Value = zonaNome              ' Zona
                .Cells(lastRowStorico, 10).Value = durataMinuti         ' Durata Minuti
                .Cells(lastRowStorico, 11).Value = IIf(IsEmpty(oraUscita), "PENDENTE", "COMPLETATO") ' Stato
                .Cells(lastRowStorico, 12).Value = wsEntrate.Cells(i, 17).Value ' Note (Col Q)
            End With
            
            lastRowStorico = lastRowStorico + 1
        End If
    Next i
    
    ' Chiudi il file giornaliero senza salvare modifiche
    wbGiornaliero.Close SaveChanges:=False
    
    MsgBox "Dati giornalieri archiviati con successo!", vbInformation
    
    Exit Sub

GestoreErrore:
    MsgBox "Errore durante l'archiviazione: " & Err.Description, vbCritical
    If Not wbGiornaliero Is Nothing Then wbGiornaliero.Close SaveChanges:=False
End Sub

' Funzione di supporto per il calcolo durata (copia anche questa nel Generatore)
Function CalcolaDurataNetta(oraEntrata As Variant, oraUscita As Variant) As Double
    Dim inizioPausa As Double, finePausa As Double
    Dim durataTotale As Double, sovrapposizione As Double
    Dim oraEntrataFrac As Double, oraUscitaFrac As Double
    
    If IsEmpty(oraEntrata) Or IsEmpty(oraUscita) Then CalcolaDurataNetta = 0: Exit Function
    If Not IsNumeric(oraEntrata) Or Not IsNumeric(oraUscita) Then CalcolaDurataNetta = 0: Exit Function
    
    inizioPausa = TimeValue("12:00"): finePausa = TimeValue("13:30")
    durataTotale = oraUscita - oraEntrata
    If durataTotale < 0 Then CalcolaDurataNetta = 0: Exit Function
    
    oraEntrataFrac = oraEntrata - Int(oraEntrata)
    oraUscitaFrac = oraUscita - Int(oraUscita)
    
    sovrapposizione = 0
    If oraEntrataFrac < finePausa And oraUscitaFrac > inizioPausa Then
        Dim inizioOverlap As Double, fineOverlap As Double
        inizioOverlap = Application.WorksheetFunction.Max(oraEntrataFrac, inizioPausa)
        fineOverlap = Application.WorksheetFunction.Min(oraUscitaFrac, finePausa)
        If fineOverlap > inizioOverlap Then sovrapposizione = fineOverlap - inizioOverlap
    End If
    
    CalcolaDurataNetta = durataTotale - sovrapposizione
    If CalcolaDurataNetta < 0 Then CalcolaDurataNetta = 0
End Function
```
