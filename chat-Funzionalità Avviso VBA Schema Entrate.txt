If Not Intersect(Target, Me.Range("L2:L201")) Is Nothing Then

Certamente. Per gestire il caso in cui il contenuto della cella **F** (es. `"TALQUALE / MONZA"`) **contiene** il testo presente in una cella di **M1:M16** (es. `"TALQUALE"`), devi invertire la logica del confronto:

- Non cercare il valore di F **intero** in M1:M16,
- ma **scorrere ogni voce in M1:M16** e verificare se è **contenuta** nel testo di F.

Ecco il codice modificato per soddisfare questa esigenza:

```vba
' >>> AVVISO SU COLONNA F IN BASE A MODIFICA DI COLONNA L (match parziale) <<<
If Not Intersect(Target, Me.Range("L2:L201")) Is Nothing Then
    Dim merciSh As Worksheet
    Set merciSh = ThisWorkbook.Sheets("MERCI")
    
    Dim iRow As Long, i As Long
    Dim nomeInF As String
    Dim clienteChiave As String
    Dim msgText As String
    
    For Each cell In Intersect(Target, Me.Range("L2:L201"))
        iRow = cell.Row
        nomeInF = Trim(Me.Cells(iRow, "F").Value)
        
        If nomeInF <> "" Then
            ' Scorri le 16 righe del foglio MERCI
            For i = 1 To 16
                clienteChiave = Trim(merciSh.Cells(i, "M").Value)
                If clienteChiave <> "" Then
                    ' Cerca se clienteChiave è contenuto in nomeInF (case-insensitive)
                    If InStr(1, nomeInF, clienteChiave, vbTextCompare) > 0 Then
                        msgText = merciSh.Cells(i, "N").Value
                        If msgText <> "" Then
                            MsgBox msgText, vbInformation, "Avviso Merce"
                            Exit For ' Esci dal ciclo: basta un match
                        End If
                    End If
                End If
            Next i
        End If
    Next cell
End If
' <<< FINE AVVISO >>>
```

### Cosa cambia rispetto al codice precedente:
- Usa `InStr(..., vbTextCompare)` per cercare **una sottostringa** (case-insensitive).
- Scorre esplicitamente le celle `M1` a `M16` invece di usare `.Find`, che non è adatto a ricerche “contiene”.
- Esce al primo match trovato (`Exit For`) per evitare messaggi multipli.

### Esempio:
- **F5** = `"TALQUALE / MONZA"`
- **M3** = `"TALQUALE"`
- → Il codice trova `"TALQUALE"` dentro `"TALQUALE / MONZA"` e mostra il contenuto di **N3**.

```vba
Private Sub Worksheet_SelectionChange(ByVal Target As Range)
    Dim ws As Worksheet: Set ws = Me
    Dim rigaDaEvidenziare As Long
    Dim intervalloRiga As Range
    Dim iCol As Integer
    
    ' Reset evidenziazione precedente (se esiste)
    If UltimaRigaEvidenziata >= 2 And UltimaRigaEvidenziata <= 201 Then
        Set intervalloRiga = ws.Range(ws.Cells(UltimaRigaEvidenziata, "B"), ws.Cells(UltimaRigaEvidenziata, "P"))
        For iCol = 1 To intervalloRiga.Columns.Count
            intervalloRiga.Cells(1, iCol).Interior.Color = ColoreOriginale(iCol)
        Next iCol
    End If
    
    ' Prepara nuova evidenziazione
    If Not Intersect(Target, ws.Range("B2:P201")) Is Nothing Then
        rigaDaEvidenziare = Target.Row
        
        ' Salva i colori originali della riga B:P
        Set intervalloRiga = ws.Range(ws.Cells(rigaDaEvidenziare, "B"), ws.Cells(rigaDaEvidenziare, "P"))
        ReDim ColoreOriginale(1 To intervalloRiga.Columns.Count)
        For iCol = 1 To intervalloRiga.Columns.Count
            ColoreOriginale(iCol) = intervalloRiga.Cells(1, iCol).Interior.Color
        Next iCol
        
        ' Applica il colore temporaneo SOLO se NESSUNA cella della riga è già colorata
        ' (escludiamo il bianco/default xlNone = -4142, ma anche altri colori significativi)
        Dim haColoreSignificativo As Boolean
        haColoreSignificativo = False
        For iCol = 1 To intervalloRiga.Columns.Count
            If ColoreOriginale(iCol) <> -4142 And ColoreOriginale(iCol) <> RGB(255, 255, 204) Then
                ' Se trovi un colore diverso dal default e dal nostro giallino, blocca
                haColoreSignificativo = True
                Exit For
            End If
        Next iCol
        
        If Not haColoreSignificativo Then
            intervalloRiga.Interior.Color = RGB(255, 255, 204) ' #ffffcc
        Else
            ' Non applicare evidenziazione: lascia i colori originali
            ' Ma comunque ricorda la riga per evitare doppie evidenziazioni
        End If
        
        UltimaRigaEvidenziata = rigaDaEvidenziare
    Else
        ' Selezione fuori dall'area: annulla traccia
        UltimaRigaEvidenziata = 0
    End If
End Sub
```

### ✅ Come funziona:
1. **Memorizza i colori originali** di ogni cella nella riga `B:P` prima di cambiare qualcosa.
2. **Prima di evidenziare una nuova riga**, ripristina quella precedente ai colori salvati.
3. **Controlla se la riga ha già un colore significativo** (es. rosso per ritardo, giallo per avviso, ecc.):
   - Se sì → **non applica** l’evidenziazione `#ffffcc`.
   - Se no (solo celle bianche o già con `#ffffcc`) → applica l’evidenziazione.
4. **Non interferisce** con la tua macro esistente che rimuove il colore in `B:F` quando si compila la colonna L.
5. **Evita doppie evidenziazioni**: una sola riga è mai evidenziata.

---

### ⚠️ Note importanti:
- Il colore predefinito (nessun riempimento) in Excel è `-4142` (`xlNone`).
- La tua regola “se la riga è già colorata, non evidenziare” è rispettata.
- Se un operatore seleziona una cella **fuori da B2:P201**, l’evidenziazione viene rimossa.
- Questa macro **non usa `EnableEvents`**, quindi non interferisce con `Worksheet_Change`.

### ❌ Problema principale:
L’array `ColoriOriginali` è **globale e singolo**.  
Questo significa che:

- Se l’utente passa velocemente da una riga a un’altra,  
- i colori della **prima riga vengono sovrascritti** da quelli della seconda durante il salvataggio,  
- e al momento del ripristino, **la prima riga viene colorata con i colori della seconda** → **corruzione visiva**.

Inoltre, `ColoriOriginali(i)` usa indici da 2 a 16 (colonne B–P), ma non è associato a una specifica riga — è un unico buffer condiviso.

---

Dobbiamo **salvare i colori solo della riga attualmente evidenziata**, e **ripristinarli subito prima di cambiarla**. Non serve un array globale complesso: basta salvarli localmente *prima* di applicare il nuovo colore, e usarli subito dopo.

```vba
    ' Ma per sicurezza, controlliamo se B:F ha un colore "significativo"
    Dim haColoreSignificativo As Boolean

    For c = 2 To 6 ' Colonne B(2) a F(6)
        Dim col As Long
```

### 🔧 Passo 1: Modifica la macro temporanea (`Worksheet_SelectionChange`)

Sostituisci **tutto** il codice della `Worksheet_SelectionChange` nel foglio `ENTRATE` con questo:

```vba
Private UltimaRigaTemporanea As Long

Private Sub Worksheet_SelectionChange(ByVal Target As Range)
    Dim ws As Worksheet: Set ws = Me
    Dim r As Long
    
    ' --- Se la selezione è fuori dall'area B2:P201, rimuovi evidenziazione temporanea ---
    If Intersect(Target, ws.Range("B2:P201")) Is Nothing Then
        If UltimaRigaTemporanea >= 2 And UltimaRigaTemporanea <= 201 Then
            RimuoviEvidenziazioneTemporanea UltimaRigaTemporanea
            UltimaRigaTemporanea = 0
        End If
        Exit Sub
    End If
    
    r = Target.Row
    
    ' --- Non fare nulla se la riga è evidenziata MANUALMENTE ---
    If Trim(ws.Range("AZ" & r).Value) = "MANUALE" Then
        If UltimaRigaTemporanea <> 0 Then
            RimuoviEvidenziazioneTemporanea UltimaRigaTemporanea
            UltimaRigaTemporanea = 0
        End If
        Exit Sub
    End If
    
    ' --- Se è la stessa riga, esci ---
    If r = UltimaRigaTemporanea Then Exit Sub
    
    ' --- Rimuovi evidenziazione temporanea precedente (solo se non è manuale!) ---
    If UltimaRigaTemporanea >= 2 And UltimaRigaTemporanea <= 201 Then
        If Trim(ws.Range("AZ" & UltimaRigaTemporanea).Value) <> "MANUALE" Then
            RimuoviEvidenziazioneTemporanea UltimaRigaTemporanea
        End If
    End If
    
    ' --- Controlla se la riga ha avvisi (es. >4h): evita di sovrascrivere ---
    Dim haColoreSignificativo As Boolean
    haColoreSignificativo = False
    Dim c As Integer
    For c = 2 To 6 ' Colonne B a F
        Dim col As Long
        col = ws.Cells(r, c).Interior.Color
        ' Ignora bianco, nessun colore, e il giallo temporaneo
        If col <> -4142 And col <> RGB(255, 255, 255) And col <> RGB(255, 255, 204) Then
            haColoreSignificativo = True
            Exit For
        End If
    Next c
    
    If haColoreSignificativo Then
        UltimaRigaTemporanea = 0
        Exit Sub
    End If
    
    ' --- Applica evidenziazione TEMPORANEA ---
    ws.Range(ws.Cells(r, "B"), ws.Cells(r, "P")).Interior.Color = RGB(255, 255, 204)
    UltimaRigaTemporanea = r
End Sub

Private Sub RimuoviEvidenziazioneTemporanea(ByVal riga As Long)
    Dim ws As Worksheet: Set ws = Me
    Dim c As Integer
    For c = 2 To 16 ' Colonne B (2) a P (16)
        If ws.Cells(riga, c).Interior.Color = RGB(255, 255, 204) Then
            ws.Cells(riga, c).Interior.ColorIndex = xlNone
        End If
    Next c
End Sub
```
